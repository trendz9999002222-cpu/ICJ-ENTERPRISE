# Beta Branch & Autonomous Workflow Directive

1. **Target Environment**: All code changes, bug fixes, and feature updates requested by the user must be committed and pushed directly to the `beta` branch (and synced with `master`) so that the Beta deployment updates automatically.
2. **Autonomous Execution**: Do not ask the user for trivial confirmations or manual button presses unless strictly necessary. Proceed directly with testing, building, committing, and pushing code updates automatically.
